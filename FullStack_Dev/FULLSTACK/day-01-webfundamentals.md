# Internet vs Web
## Internet
- **internet** is a network of interconnected computers globally.
- web is one of the internet service. 
## Web 
- **world wide web** is an internet service.
- it is a system of interlinked resources accessed through internet.

# URL
- **example**:https://www.example.com:43/products?id=56#hahguo

- **www.example.com**-domain name
- **:43**-port
- **/products**-path
- **?id=56**-query string
- **#hahguo**-fragment identifier
